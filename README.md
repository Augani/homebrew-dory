# Dory Homebrew Tap

Install [Dory](https://github.com/Augani/dory) — a free, open-source native macOS app for
Docker and Linux containers on Apple Silicon Macs running macOS 14 or later:

```sh
brew install --cask Augani/dory/dory
```

The cask here is updated automatically by Dory's release workflow.
Intel support is planned for a later release phase.
